# Origin

LunalithCore is a provider-neutral extraction of continuity and interaction algorithms developed in the private Bridget prototype.

This repository was reconstructed from creator-supplied current source files on 2026-09-13. It contains newly separated public-facing types and documentation rather than a copy of the private application. Personal data, provider integrations, autonomous sensing, UI, voice, and Bridget-specific identity material were intentionally excluded.

Public attribution and licensing remain the creator's decision. Until a license is deliberately added, all rights are reserved.
